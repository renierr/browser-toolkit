# A-Frame Shelter

The A-frame is a simple, sturdy shelter that provides good protection from elements. Quick to build and works in many environments.

## When to Use

- Quick shelter needed
- Need protection from rain and wind
- Limited materials available
- Snow is too shallow for snow cave

## Materials Needed

- Ridgepole: Long, strong pole (10-14 feet)
- Poles: Several 5-7 foot poles
- Covering: Branches, bark, leaves, pine boughs, tarp

## Building Steps

### 1. Set the Ridgepole

1. Find two sturdy supports (trees, rocks)
2. Place ridgepole about 3 feet off ground
3. Or prop on forked stakes

### 2. Create the Frame

1. Lean poles against both sides of ridgepole
2. Form an A shape
3. Space poles about 1 foot apart
4. Creates the skeleton for covering

### 3. Add Covering

1. Start from bottom, work up
2. Overlap like shingles
3. Use: pine boughs, branches, bark, leaves
4. Make layers thick

### 4. Close the Ends

1. Weave branches across ends
2. Add extra covering material
3. Leave one end partially open for entrance

### 5. Create Bed

1. Fill floor with pine boughs or leaves
2. Add 6+ inches of material
3. Creates insulation from ground

:::tip
Build smaller than you think - easier to heat and maintain.
:::

## Improvements

- Add fire reflector on open side
- Create windbreak with logs
- Add side walls for more protection
- Use tarp if available for covering
