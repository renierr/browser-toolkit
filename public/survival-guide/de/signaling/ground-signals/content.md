# Boden-Luft-Signale

Große, von Flugzeugen aus sichtbare Signale können dein Leben retten. Erschaffe diese Signale auf offenem Gelände.

## Universelle Notsignale

Mache Signale mindestens 3 Meter breit, 90 cm dick. Verwende Materialien, die mit Boden kontrastieren.

| Signal | Bedeutung                   |
| ------ | --------------------------- |
| V      | Benötige Hilfe              |
| X      | Benötige medizinische Hilfe |
| I      | Benötige Vorräte            |
| →      | Reise in diese Richtung     |

## Signale erschaffen

1. **Wähle Standort**
   - Offener Bereich, sichtbar aus der Luft
   - In der Nähe deines Unterstands, aber nicht Fluchtwege blockierend

2. **Verfügbare Materialien verwenden**
   - Felsen, Scheite, Äste
   - Kleidung, Ausrüstung
   - Verbrannte Bereiche (Holzkohle)

3. **Mache groß**
   - Mindestens 3 Meter breit
   - Dicke, sichtbare Linien

4. **Bewegung hinzufügen**
   - Winke mit weißem Tuch
   - Spiegelsignal
   - Feuer für Aufmerksamkeit

:::tip
Flugzeuge werden oft zurückkreisen, wenn sie dich sehen. Gib nicht auf, wenn sie vorbeifliegen.
:::

## Signale machen

- [ ] Leeren dunklen Boden für Kontrast
- [ ] Arrange Felsen oder Scheite im Muster
- [ ] Feuer für Aufmerksamkeit hinzufügen
- [ ] In der Nähe von Wasser als Referenz platzieren
- [ ] Bereit sein zu bewegen, wenn Gefahr sich nähert
