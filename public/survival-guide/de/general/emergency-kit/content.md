# Notfallkit-Checkliste

Vorbereitet zu sein kann dein Leben retten. Hier ist, was in ein grundlegendes Notfall-/Überlebenskit gehört.

## Wesentliches

- [ ] Wasser (4 Liter pro Person pro Tag)
- [ ] Haltbares Essen
- [ ] Multi-Tool oder Messer
- [ ] Feuerstarter (Streichhölzer, Feuerzeug, Ferro-Stab)
- [ ] Taschenlampe + Extra Batterien
- [ ] Erste-Hilfe-Kasten
- [ ] Pfeife
- [ ] Staubmaske
- [ ] Handy + tragbare Ladegerät
- [ ] Wichtige Dokumente (Kopien)

## Unterkunft

- [ ] Plane oder Notfalldecke
- [ ] Paracord (15 Meter)
- [ ] Klebeband
- [ ] Schlafsack oder Rettungsdecke

## Navigation

- [ ] Kompass
- [ ] Karten der Gegend
- [ ] GPS-Gerät (wenn verfügbar)

## Werkzeuge

- [ ] Schraubenzieher
- [ ] Zange
- [ ] Schraubenschlüssel
- [ ] Dosenöffner
- [ ] Schere

## Hygiene

- [ ] Sanitärvorräte
- [ ] Feuchttücher
- [ ] Plastiktüten

## Fahrzeug-Kit (falls zutreffend)

- [ ] Starthilfekabel
- [ ] Taschenlampe
- [ ] Reifenreparaturkit
- [ ] Leuchtfeuer
- [ ] Eiskratzer
- [ ] Decke

:::tip
Prüfe dein Kit zweimal jährlich. Ersetze abgelaufene Artikel und aktualisiere für saisonale Bedürfnisse.
:::

## Bug-Out-Tasche (Schnellgriff)

Halte eine separate, leichtere Tasche bereit:

- [ ] Wasser (72-Stunden-Vorrat)
- [ ] Essen (72-Stunden-Vorrat)
- [ ] Erste-Hilfe
- [ ] Multi-Tool
- [ ] Taschenlampe
- [ ] Pfeife
- [ ] Staubmaske
- [ ] Plane
- [ ] Radio
- [ ] Bargeld
