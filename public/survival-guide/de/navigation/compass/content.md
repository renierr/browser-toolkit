# Einen improvidierten Kompass herstellen

Ein Kompass hilft dir, Richtung zu finden. So hergestellt mit minimalen Materialien.

## Methode 1: Magnetisierte Nadel

### Was du brauchst

- Nadel oder Stück Stahl
- Magnet (oder Seide, Wolle, oder Erdfeld)
- Etwas zum Schwimmen (Blatt, Kork, Papier)

### Schritte

1. **Magnetisiere die Nadel**
   - Reibe eine Richtung auf Magnet 50+ Mal
   - Oder reibe auf Seide/Wolle kräftig

2. **Baue einen Schwimmer**
   - Lege Nadel auf Blatt, Kork oder Papier

3. **Lege in Wasser**
   - Die Nadel wird sich Nord-Süd ausrichten
   - Warte, bis sie sich beruhigt

## Methode 2: Schatten-Kompass

1. Lege Stock in den Boden
2. Markiere Schattenspitze
3. Warte 15-20 Minuten
4. Markiere neue Position
5. Linie zwischen Markierungen ist ungefähr Ost-West

## Methode 3: Uhr-Kompass

1. Zeige Stundenzeiger auf Sonne
2. Zeige zwischen Stundenzeiger und 12 ist Süden (Nördliche Halbkugel)

:::tip
Übe diese Methoden, bevor du sie brauchst. Im Überleben willst du Fähigkeiten, keine Experimente.
:::

## Richtung bewahren

- [ ] Notiere Richtung vor dem Start
- [ ] Erinnere dich an Sonnenposition
- [ ] Verwende Orientierungspunkte
- [ ] Mache Wegmarkierungen
- [ ] Folge Wasserläufen
